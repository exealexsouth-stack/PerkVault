# PerkVault Android MVP (source only)
Open this directory in Android Studio with JDK 17, Android SDK 35 and Gradle 8.9. Sync dependencies, then Build > Build APK(s). No API keys required. This environment has no Android SDK or Gradle, so compilation and device testing have not been performed. No APK is included.

Features: user-enabled draggable overlay, Quick Settings tile, manual paste, image picker and share receiver (multiple images), bundled ML Kit OCR with basic heuristic extraction and review, local JSON wallet, search, status/type filters, duplicate code check, copy, mark used, manual savings, expiry archive view and approximate daily expiry reminders. No notification listener or access to other apps' notifications. Android notification permission is only for own reminders. Overlay foreground service displays its own required service notification.

Usage: enable overlay permission, return to app and enable again. Stop overlay before payment; it is not automatically limited to selected apps. Do not bypass protected screens. Quick Settings tile is added through system tile editor. OCR is best effort; confirm every field. Source app selection is manual unless recognized in OCR. Gift cards and loyalty are stored as records, not live balances. No cloud sync, affiliate integrations, ads, editing existing entries, automatic source detection or production security review. Reminder scheduling is inexact and must be re-established by opening app after reboot. Test on physical devices and payment reward screens before distribution; overlay dialogs and clipboard behavior may vary. Play Store foreground service and overlay policy review required.

## Build on GitHub Actions (no PC required)
Create a GitHub repository and upload the extracted project contents at its root, including `.github/workflows/android.yml` (hidden folder). Do not upload only the ZIP. If the mobile uploader omits hidden folders, create `.github/workflows/android.yml` using GitHub's Add file > Create new file and paste the supplied workflow. Open Actions > Build Android APK > Run workflow. After a successful run, download PerkVault-debug-APK from Artifacts, extract it, and install app-debug.apk. This is a debug build, not a Play Store release. Gradle 8.9 is installed by the workflow, so no wrapper is required. GitHub Actions has not been executed or verified here.
